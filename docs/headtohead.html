How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one for a short-term rental property manager, Hostaway or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), logged out of ChatGPT so there's no memory or personalization.
  • Open comparison question: "Hostaway vs. {rival}: which should I choose?" Asked once per order (12 answers) — this is where the qualitative reasoning and citations below come from. It is not repeated, so a single odd answer could be noise.
  • Both orders are asked because ChatGPT can lean toward whichever brand is named first. For Guesty, Lodgify, Track and Uplisting it doesn't matter — Hostaway sweeps 10 of 10 either way. For Hospitable and OwnerRez, the result flips completely by order: Hostaway sweeps when named first, but loses every run (0 of 5) when the rival is named first instead — the clearest order effect seen across any project in this suite so far.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any engine besides ChatGPT, and any run while logged in.
